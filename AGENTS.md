# Codex instructions

Before making changes, read the umbrella repository's `docs/ai/README.md` in full. In the full local monorepo tree, use `../../../../../docs/ai/README.md` from `app/public/wp-content/plugins/bcc-search/`. In a standalone or cloud checkout where that relative path is unavailable, clone the umbrella repository and read its `docs/ai/README.md` in full.

`bcc-search` owns search functionality. It depends on `bcc-core`; do not treat search as owned by `bcc-core`.
